What is CSS?


CSS is used to control the style of a web document in a simple and easy way. CSS is the acronym for “Cascading Style Sheet”. CSS is a simple design language intended to simplify the process of making web pages presentable. Before CSS came, designers were dependent on the standard formatting techniques of HTML which is difficult for those who develop big web sites. The solution to this problem is to use CSS to save a lot of work and time. It also improves the readability, organization and maintainability.

Application of CSS


CSS saves time - reusability of same sheet in multiple HTML pages. This defines a style for each HTML element and applies it to as many Web pages as you want.

Pages load faster - no need to write HTML tag attributes, just write one CSS rule of a tag and apply it to all the occurrences of that tag. Less code means faster download times.

Easy maintenance - simply change the style, and all elements in all the web pages will be updated automatically.

Global web standards - start using CSS in all the HTML pages to make it compatible to other browsers.

Three Ways to Use CSS


We can add CSS code in any combination of three different ways:


  1. 1. Inline Style - CSS code is placed directly into an HTML element within the <body> section of a web page.
  2. 2. Internal Style Sheet - CSS code is placed into a separate, dedicated area within the section of a web page.
  3. 3. External Style Sheet - CSS code is placed into a separate computer file and then linked to a web page.

Inline Style

To define an inline CSS style, we simply add the style attribute to an HTML element with the CSS declaration as the attribute value:


              <h2 style="color:red;"> CAUTION: Icy Road Conditions </h2 >
              <h2> Please Slow Down! </h2>

An inline style declaration is highly specific and formats just one element on the page. No other elements, including other <h2> elements on the page, will be affected by this CSS style.


Internal Style Sheet

To use an internal CSS style sheet, we add a section within the <head> of the page. All our CSS declarations go within this section:


              <html>
              <head>
              <style type="text/css">
              h2 {color:red;}
              </style>
              </head>
              <body>
              <h2> CAUTION: Icy Road Conditions </h2>
              <h2> Please Slow Down! </h2>
              </body>
              </html>

Styles declared in the internal style sheet affect all matching elements on the page. In this example, all <h2> page elements are displayed in the color red.


Since formatting declarations are entirely in the <head> section, away from the actual page content, internal CSS style sheets do a much better job than inline styles at separating content from presentation.


External Style Sheet

To use an external CSS style sheet, we create a new file (with a .css extension) and write our style declarations into this file. We then add a <link> element into our HTML file, right after the opening <head> tag:


style.css (separate file):


              h2 {color:red;}

example.html file:


              <html>
              <head>
              <link rel="stylesheet" type="text/css" href="style.css"/>
              </head>
              <body>
              <h2> CAUTION: Icy Road Conditions </h2>
              <h2> Please Slow Down! </h2>
              </body>
              </html>

CSS Terminology and Syntax


Now let's take a closer look at how we write CSS code. The correct syntax of a CSS declaration is:


              selector {property:value;}


Internal and external style sheets use this identical CSS syntax. Internal style sheets must use the opening and closing <style> tags to surround the CSS code, while external style sheets do not use the <style> element. A semicolon must be placed after each CSS declaration. Omitting this semicolon is the single most common mistake made by those learning CSS.

Setting Multiple Properties


We can define as many properties as we wish for a selector:


              p {color:red;font-style:italic;text-align:center;}

In this example, all text within paragraph elements will show in red italics that is centered on the page.


              p {
              color: red;
              font-style: italic;
              text-align: center;
              }

Just as with HTML, browsers ignore space characters in CSS code. Many designers take advantage of this fact by placing the opening and closing curly brackets on their own dedicated lines. Each of the property and value pairings are placed on its own indented line with a space after the colon. This makes the code far easier to read.

CSS Background


Apply colors and background colors to your website are the main focus of this lesson. The advanced methods to position and control background images with the use of the following CSS properties listed below:


  • Color
  • background-color
  • background-image

Foreground color: the 'color' property

The color property describes the foreground color of an element. For example, we want all headlines in a document to be dark red. The headlines are all marked with the HTML element <h1>. The code below sets the color of <h1> elements to be red.


Colors can be entered as hexadecimal values as in the example above(#ff0000), or you can use the names of the colors (“red”) or RGB-values(RGB(255,0,0)).


colorstyles.html


              <html>
              <head>
              <title>Colors using CSS</title>
              <link rel=”stylesheet” href=”colorstyles.css” type=”text/css”/>
              </head>
              <body>
              <h1>All heading is in Blue</h1>
              <p>CSS is an easy way for your webpage</p>
              </body>
              </html>

colorstyles.css


              h1 {color:blue;}

The background-color property

The background-color property describes the background color of elements. The element <body> contains all the content of an HTML document. To change the background color of an entire page, the background-color property should be applied to the <body> element


Apply background colors to other elements including headlines and text. Different background colors are applied to <body> and <h1> elements. Apply two properties to <h1> by dividing them by a semicolon.


backgroundcolor.css


              body {background-color: #FFCC66;}
              h1 {color:990000; background-color: #FC9804;}

backgroundcolor.html


              <html>
              <head>
              <title>CSS Background Colors,/title>
              <link rel=”stylesheet” href=”backgroundcolor.css” type=”text/css”/>
              </head>
              <body>
              <h1>This is a heading with a background color</h1>
              <p>CSS Background colors</p>
              </body>
              </html>

Background images

The CSS property background-image is used to insert a background image. To insert the image as background image for a web page, simply apply the background-image property to <body> and specify the location of the image.


bgimage.html


              <html>
              <head>
              <title>CSS Background image</title>
              <link rel=”stylesheet” href=”bgimage.css” type=”text/css”/>
              </head>
              <body>
              <h1> Pane Design Background</h1>
              <p>CSS Background image</p>
              </body>
              </html>

bgimage.css


              body {background-color: #FFCC66;
                background-image:url(“pane.png”);}
               h1 {color:#990000; background-color:#FC9804;}

Notice how we specified the location of the image as url (“pane.png”). This means that the image is located in the same folder as the style sheet. You can also refer to images in other folders using url(“…/images/pane.png”) or even on the Internet indicating the full address of the file: url say http://www.yahoo.com/pane.png.


Repeat background image

The property background-repeat controls by default the image displayed repeatedly both horizontally and vertically (tiled) to cover the entire screen.


The table below outlines the four different values for background-repeat.


Value Description
background-repeat: repeat-x The image is repeatedly horizontally
background-repeat: repeat-y The image is repeatedly vertically
background-repeat: repeat The image is repeated both horizontally and vertically
background-repeat: no-repeat The image is not repeated

As an example, to avoid repetition of a background image the code should look like the CSS file written in Notepad.


bgimage.css


              body {background-color: #FFCC66;
                background-image: url(“pane.png”);
                background-repeat: no-repeat;}
               h1 {color:#990000;
                background-color:#FC9804;}

Lock background image

The property background-attachment specifies whether a background picture is fixed or scrolls along with the containing element. A fixed background image will not move with the text when a reader is scrolling the page, whereas an unlocked background image will scroll along with the text of the web page. The table below outlines the two different values for background-attachment. The difference can be viewed in run time during browsing.


Value Description
background-attachment: scroll The image scrolls with the page - unlocked
background-attachment: fixed The image is locked

This code will fix the background image


              body {background-color: #FFCC66;
                background-image: url(“pane.png”);
                background-repeat: no-repeat;
                background-attachment: fixed;}
               h1 {color:#990000; background-color:#FC9804;}

Place background image

By default, a background image will be positioned in the top left corner of the screen. The property background-position allows you to change this default and position the background image anywhere you like on the screen. There are numerous ways to set the values of background-position. On the other hand, all of them are formatted as a set of coordinates.


The table below gives some examples.


Value Description
background-position: 2cm 2cm The image is positioned 2cm from the left and 2cm down the page.
background-position: 50% 25% The image is centrally positioned and one fourth down the page.
background-position: top right The image is positioned in the top-right corner of the page.

The code example positions the background image in the bottom right corner.


bgimage.css

              body {background-color: #FFCC66;
              background-image: url(“pane.png”);
              background-repeat: no-repeat;
              background-attachment: fixed;
              background-position: right bottom;}
              h1 {color:#990000; background-color:#FC9804;}

The property background is a short hand for all the background properties listed in this lesson. With background you can compress several properties and thereby write your style sheet in a shorter way which makes it easier to read.


For example, the CSS have all these five lines:


              background-color: #FFCC66;
              background-image: url(“pane.png”);
              background-repeat: no-repeat;
              background-attachment: fixed;
              background-position: right bottom;

Using background the same result can be achieved in just one line of code:


              Background”#FFCC66 url(“pane.png”)no-repeat fixed right bottom;

The list of order is as follows:


              [background-color]|[background-image]|[background-repeat]|
              [background-attachment]|[background-position]

If a property is left out, it will automatically be set to its default value. For example, if backgroundattachment and background-position are taken out of the example:


              background:#FFCC66 url(“pane.png” no-repeat;

These two properties that are not specified would merely be set to their default values which are scroll and top left.

Text transformation

The text-transform property controls the capitalization of a text. You can choose to capitalize, use uppercase or lowercase regardless of how the original text looks in the HTML code. There are four possible values for text-transform:


  • capitalize - capitalizes the first letter of each word. For example: “jose rizal” will be “Jose Rizal”.
  • uppercase - converts all letters to uppercase. For example: “jose rizal” will be “JOSE RIZAL”.
  • lowercase - converts all letters to lowercase. For example: “JOSE RIZAL” will be “jose rizal”.
  • none - no transformations - the text is presented as it appears in the HTML code.

As an example, we will use a list of names. The names are all marked with <li> (list item). The names must be capitalized and headlines to be presented in uppercase letters.


text_transform.css


              h1 {text-transform: uppercase;}
              li {text-transform: capitalize; }

text_transform.html


              <html>
              <head>
              <title>CSS Text transformation</title>
              <link rel="stylesheet" href="text_transform.css" type="text/css">
              </head>
              <body>
              <h1>this heading is uppercase</h1>
              <ul>
              <li>jose rizal</li>
              <li>andres bonifacio</li>
              <li>emilio aguinaldo</li>
              <li>juan luna</li>
              <li>apolinario mabini</li>
              <li>diosdado macapagal</li>
              <li>ramon magsaysay</li>

              <p>Notice, how CSS makes all the names capitalized</p>

CSS Fonts


In this lesson you will learn about fonts and how they are applied using CSS. The following CSS properties will be described:


Font family

The property font-family is used to set a prioritized list of fonts to be used to display a given element or web page. If the first font on the list is not installed on the computer used to access the site, the next font on the list will be tried until a suitable font is found.


There are two types of names used to categorize fonts: family-names and generic families. The two terms are explained below.


  • Family-name - Examples of a family-name (often known as “font”) can be “Arial”, “Times New Roman” or “Tahoma”.
  • Generic family - Generic families can best be described as groups of family-names with uniformed appearances. An example is sans-serif, which is a collection of fonts without “feet”.

When you list fonts for your website, you naturally start with the most preferred font followed by some alternative fonts. It is recommended to complete the list with a generic font family. That way at least the page will be shown using a font of the same family if none of the specified fonts are available.


An example of a prioritized list of fonts could look like this:


font_family.css


              h1 {font-family: arial, verdana, sans-serif;}
              h2 {font-family: “Times New Roman”, serif; }

font_family.html


              <html>
              <head>
              <title>CSS Text transformation</title>
              <link rel="stylesheet" href="font_family.css" type="text/css">
              </head>
              <body>
              <h1>This heading will display the font family (Arial, Verdana, Sans-serif)</h1>
              <h2>This heading will display the font family (Times New Roman, serif)</h2>
              </body>
              </html>

Output:



Headlines marked with <h1> will be displayed using the font “Arial”. If this font is not installed on the user's computer, “Verdana” will be used instead. If both of these fonts are unavailable, a font from the sans-serif family will be used to show the headlines.

The property font-variant is used to choose between normal or small-caps variant of a font. A small-caps font is a font that uses smaller sized capitalized letters (upper case) instead of lower case letters.

CSS Borders


Borders can be used for many things, for example as a decorative element of to underline a separation of two things. CSS gives you nonstop options when using borders in your pages. The following are listed below:


  • border-width
  • border-color
  • border-style
  • border

The width of borders

The width of borders is defined by the property border-width, which can obtain the values thin, medium, and thick, or a numeric value, indicated in pixels.


The color of borders

The property border-color defines which color the border has. The values are the normal color-values for example “#123456”, “rgb(123, 123, 123)” or “yellow”.


Type of borders

There are different types of borders to choose from. To illustrate this, we will take a look at a document where we define different borders for <h1>, <h2>, <ul>, and <p>


borders.css


              h1 { border-width: thick;
                border-style: dotted;
                border-color:gold;}
               h2 { border-width: 20px;
                border-style: outset;
                border-color:red;}
               p { border-width: 1px;
                border-style: dashed;
                border-color: blue;}
               ul { border-width: thin;
                border-style: solid;
                border-color: orange;}

borders.html


              <html>
              <head>

              </head>

              <h2>The border with 20px outset in red color</h2>
              <p>The three properties described above can be put together by each element and
              thereby produce different borders. </p>
              <ul>unordered list</ul>
              </body>

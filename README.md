# CSS Tutorials and Exercises

A static educational website for learning and practicing basic CSS concepts. The project presents our professor's CSS module as a multi-page web experience with tutorials, exercises, quizzes, and team information.

## Pages

- `Home.html` - Project overview and navigation
- `CSS.html` - CSS tutorials and topic examples
- `Exercises.html` - Practice exercises with pop-up answers
- `Test.html` - Interactive quiz with score and grade results
- `Team.html` - Project team members

## Features

- Responsive navigation for desktop and mobile screens
- CSS tutorial examples with images
- Practice exercises and reference answers
- Automated quiz scoring and grade equivalents
- Consistent styling across all pages
- Hidden page scrollbars while preserving scroll functionality
- Responsive layouts for desktop, tablet, and mobile screens
- Mobile navigation menus and reflowed tutorial, exercise, quiz, and team content

## Run the Website

Open `Home.html` in a web browser. All pages and assets are local, except for the externally loaded Montserrat and Font Awesome resources.
